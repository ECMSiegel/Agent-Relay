# Agent Coordination

This folder is the kit. Follow the project's existing instructions as well as these coordination procedures.

- “Set up a team here” or “help me split this work”: read this kit's `.agents/skills/team-init/SKILL.md`. Run this kit's initializer from the intended project.
- “Join this project”: read the project's `team/PROTOCOL.md` and this kit's `.agents/skills/team-join/SKILL.md`. Use the project's own `team/team.py` launcher.
- “Where are we?”: follow this kit's `.agents/skills/team-status/SKILL.md` for a read-only summary.

When developing the kit, edit only this copy. Use sample projects under `examples/` or disposable fixtures for testing. Keep all other workspace tools, boards and projects outside the development scope.
